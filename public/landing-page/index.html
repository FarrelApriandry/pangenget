Pencatatan natural tanpa puluhan dropdown

Isi formulir bertingkat hanya memperlambat eksekusi. Pangenget membaca kalimat natural Anda dalam bahasa Indonesia, mengekstrak kategori, prioritas, dan tenggat waktu secara instan.

Tag Kategori Otomatis

Tambahkan tanda pagar seperti #kerjaan, #pribadi, atau #kuliah. Tugas langsung dikelompokkan ke ruang kerja yang tepat tanpa perlu memindahkan folder.

Input: Siapkan slide presentasi #proyek
→ Kategori: Proyek

Prioritas Berbasis Simbol

Ketik !urgent, !tinggi, atau !rendah. Sistem menandai tingkat kepentingannya seketika, memberi bobot visual agar Anda tahu apa yang harus dieksekusi pertama.

Input: Perbaiki bug server produksi !urgent
→ Prioritas: URGENT (Wajib hari ini)

Pengenal Waktu Fleksibel

Mengenali kata bahasa Indonesia seperti besok, lusa, nanti malam, atau jam spesifik seperti jam 2 siang dan jam 14:30.

Input: Bayar tagihan internet besok jam 3 sore
→ Tenggat: Besok, 15:00 WIB

Mode Fokus: Hanya satu tugas di layar

Melihat daftar panjang 30 tugas memicu kepanikan dan menunda pekerjaan. Mode Fokus di Pangenget membersihkan seluruh antarmuka dan hanya menyisakan satu tugas utama Anda.

Timer Terintegrasi: Pilih Pomodoro 25 menit untuk sprint singkat, atau Deep Work 50 menit untuk penyelesaian proyek berat.
Ceklis Subtask di Tempat: Eksekusi langkah-langkah mikro langsung dari layar fokus tanpa perlu kembali ke halaman daftar.
Generator Suara Ambient: Pemutar white-noise dan nada fokus sintetis menggunakan Web Audio API langsung dari peramban—tanpa buffering.

Transparansi

Mengapa Pangenget 100% gratis?

Pangenget bukan produk ventura yang bertujuan membakar uang lalu memeras langganan bulanan. Ini adalah utilitas yang dibuat oleh Fapri untuk pemakaian pribadi dan rekan kerja terdekat.

Neon Serverless PostgreSQL

Data Anda disimpan di infrastruktur cloud serverless Neon dengan isolasi kolom user_id. Database berskala otomatis dan hemat sumber daya saat tidak digunakan.

Neon Auth Terkelola

Autentikasi menggunakan Better Auth yang terkelola resmi di Neon. Kata sandi di-hash dengan standar industri dan sesi login disimpan secara aman di peramban Anda.

Akses Teman & Komunitas

Pendaftaran dikelola langsung lewat pengajuan email ke fapriandry@gmail.com. Kami menjaga server tetap ringan dan digunakan oleh orang-orang yang memang membutuhkannya.

Pertanyaan Umum

Bagaimana cara mendapatkan akun untuk masuk? +
Klik tombol "Masuk" di navigasi atas, lalu pilih tab "Minta Akses". Masukkan alamat email Anda dan pesan singkat. Permintaan akan langsung diteruskan ke Fapri Andry (fapriandry@gmail.com) dan akun akan dibuatkan di sistem.
Apakah data tugas saya bisa diakses orang lain? +
Tidak. Setiap baris tugas di database PostgreSQL terikat pada user_id unik akun Anda. Query data selalu memfilter berdasarkan sesi akun yang sedang aktif.
Apakah aplikasi ini bisa dipakai offline? +
Mode Fokus dan timer dapat berjalan tanpa koneksi internet. Sinkronisasi tugas ke cloud membutuhkan koneksi untuk memperbarui catatan di database Neon PostgreSQL.
Teknologi apa yang digunakan untuk membangun Pangenget? +
Pangenget dibangun menggunakan Astro 5 SSR, React 19, TypeScript, Tailwind CSS, Lucide Icons, Drizzle ORM, dan Neon Serverless PostgreSQL dengan Neon Auth.
